01 / INTEGRITY

Was the record altered after the fact?

If logs live on the vendor's own servers, the vendor can edit them — by accident, by pressure, or by court order. An audit trail you can edit is a diary. Auditors know this, which is why self-hosted logs carry an asterisk.

02 / ATTRIBUTION

Can you prove WHICH agent did it?

Not a name in a config file — a cryptographically verifiable identity. ProofChain agents are soulbound NFTs on X1. No central registry, no forged credentials, no "that wasn't our agent" debates.

03 / CONTEXT

Does the record capture intent, not just output?

A success string proves nothing. ProofChain records intent → context → decision → execution → outcome for every action. The regulator wants the reasoning, not just the result.
