## Intent-to-Execution Evidence Chain (IEEC)

The IEEC pattern (introduced in the OpenKedge protocol) cryptographically links five elements:

1. **Intent** — What was the agent asked to do?
2. **Context** — What state was the system in?
3. **Policy Decision** — What rules were evaluated?
4. **Execution Boundaries** — What permissions did the agent have?
5. **Actual Outcome** — What happened?

ProofChain captures all five elements in every HXMP memo record. This IS the IEEC implementation.
