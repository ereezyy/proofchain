Frequently asked questions

What counts as an API request?

Each call to any ProofChain API endpoint counts as one request. On the Free tier, you get 100 requests per day — enough to verify agents and pull audit trails for development. Pro unlocks unlimited usage for production workloads.

How does the 7-day money-back guarantee work?

If you're not satisfied with Pro within 7 days of purchase, email support@proofchain.dev and we'll refund your payment in full — no questions asked. We want you to be confident that ProofChain is the right compliance platform for your agents.

Can I upgrade from Free to Pro later?

Yes. All your existing agent registrations, audit trails, and compliance reports carry over seamlessly. You just get more — API key access, unlimited requests, scheduled reports, and priority support.

What is an API key and why do I need one?

An API key is a unique identifier that authenticates your requests to ProofChain's Pro endpoints. It allows unlimited access, enables scheduled reporting, and lets us provide priority support. Free tier users access the public API without a key.

Do you offer custom enterprise plans?

Yes. For organizations with 10+ agents, dedicated compliance engineers, or on-premises deployment requirements, contact enterprise@proofchain.dev for a tailored plan.
